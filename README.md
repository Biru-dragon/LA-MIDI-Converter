### Requirement
- [Python 3.10](https://www.python.org/downloads/)

### What is this
A simple converter for turning MIDI files into game maps of the game [Logic Arrows on Steam](https://store.steampowered.com/app/4210250/Logic_Arrows/).

### How to use it
A simple `python midi_to_arrows.py` with a MIDI file next to the script.
